# PipeCounter AI — Система подсчета труб на фото с помощью нейросети

Комплексное решение на базе глубокого машинного обучения для автоматического обнаружения, локализации, измерения диаметров и подсчета круглых срезов труб на фотоснимках.

Нейросеть специально оптимизирована для работы со сложными индустриальными условиями:
- **Разные калибры**: одновременное обнаружение мелких, средних и крупногабаритных труб в одном кадре.
- **Вложенные трубы**: распознавание труб, вставленных одна в другую (внутренние и внешние контуры).
- **Плотная укладка**: гексагональные связки, пирамидальные штабели, плотные пачки в стяжках с перекрытиями.
- **Различные материалы и текстуры**: сталь, нержавейка, ржавчина, оцинковка, черный чугун, полипропиленовые и ПНД трубы.
- **Любые типы освещения**: тени в полостях труб, солнечные блики, фаски срезов, фоны складов, земли или кузовов.

## 3. Использование: подсчет через командную строку

Основная консольная утилита для вызова детекции — [count_pipes.py](file:///c:/Users/VIGOK/Downloads/%D1%82%D1%80%D1%83%D0%B1%D1%8B/count_pipes.py).

### 3.1. Подсчет на одном фото
```bash
python count_pipes.py photo.jpg
```
*В Windows PowerShell (если `python` не в PATH):*
```powershell
py -3.11 count_pipes.py "C:\Users\VIGOK\Downloads\images.jpg"
```
**Вывод в консоль:**
```text
images (1).jpg: 42
```

### 3.2. Подсчет сразу по всей папке с фотографиями
Скрипт по очереди обработает все изображения в указанной директории и выведет количество для каждого файла, а также суммарный итог:
```bash
python count_pipes.py my_photos/
```
**Пример вывода:**
```text
bundle_01.jpg: 18
bundle_02.jpg: 42
bundle_03.jpg: 12
Всего: 72
```

### 3.3. Режим «только число» (флаг `-q` / `--quiet`)
Предназначен для интеграции в автоматизированные конвейеры, базы данных, 1C или микросервисы. Выводит строго целочисленное значение в `stdout`:
```bash
python count_pipes.py photo.jpg -q
```
**Вывод:**
```text
42
```

### 3.4. Сохранение размеченного изображения (флаг `-o` / `--output`)
Скрипт обводит все найденные трубы окружностями соответствующего диаметра, нумерует их, наносит перекрестие центра и плашку со статистикой:
```bash
python count_pipes.py photo.jpg -o result.jpg
```
Если указана папка, размеченные файлы сохранятся в указанный каталог:
```bash
python count_pipes.py input_folder/ -o output_folder/
```

### 3.5. Параметры тонкой настройки детекции

| Параметр | По умолчанию | Описание | Когда менять |
|---|:---:|---|---|
| `--threshold` | `0.32` | Порог уверенности нейросети (от 0.05 до 0.90). | Увеличьте (например, до `0.40`), если есть ложные срабатывания на складском мусоре. Уменьшите (до `0.22 - 0.28`), если пропускаются сильно затененные трубы. |
| `--min-diameter` | `6.0` | Минимальный диаметр трубы в пикселях. | Отсекает мелкие круглые артефакты, гайки, гравий или текстурный шум фона. |
| `--max-diameter` | `500.0` | Максимальный диаметр трубы в пикселях. | Отсекает слишком крупные объекты в кадре, не являющиеся трубами. |
| `--weights` | `weights/pipe_counter_best.pth` | Путь к файлу весов обученной модели. | Укажите при использовании альтернативных или дообученных весов. |

**Пример команды с пользовательскими порогами:**
```bash
python count_pipes.py photo.jpg --threshold 0.35 --min-diameter 12 --max-diameter 350 -o out.jpg
```

## 4. Подготовка собственного датасета

Нейросеть поддерживает **3 наиболее распространенных формата разметки**. Скрипт обучения определяет формат автоматически.

Датасет должен быть разделен на две части:
- **`train`** — обучающая выборка (70–85% от всех снимков).
- **`val`** — проверочная выборка (15–30% снимков) для контроля точности и переобучения.

---

### Вариант 1: Формат YOLO (Стандартный, рекомендуется)
Используется большинством современных инструментов разметки: **Roboflow**, **CVAT**, **Label Studio**, **AnyLabeling**.

#### Структура директорий:
```text
my_dataset/
├── images/
│   ├── train/
│   │   ├── photo_001.jpg
│   │   └── photo_002.jpg
│   └── val/
│       └── photo_003.jpg
└── labels/
    ├── train/
    │   ├── photo_001.txt
    │   └── photo_002.txt
    └── val/
        └── photo_003.txt
```
*(Также поддерживается структура `my_dataset/train/images/` и `my_dataset/train/labels/`).*

#### Формат файлов разметки `.txt`:
Каждая строка соответствует одной обнаруженной трубе:
```text
<class_id> <x_center> <y_center> <width> <height>
```
- `<class_id>` — номер класса (обычно `0`).
- `<x_center>`, `<y_center>` — координаты центра трубы, нормализованные от `0.0` до `1.0` (делится на ширину и высоту фото).
- `<width>`, `<height>` — ширина и высота описанного квадрата трубы, нормализованные от `0.0` до `1.0`.

**Пример `photo_001.txt`:**
```text
0 0.51234 0.34567 0.12000 0.12150
0 0.72410 0.34210 0.11800 0.11900
0 0.31200 0.55400 0.08500 0.08550
```

---

### Вариант 2: Формат JSON
Удобен при выгрузке из собственных баз данных или кастомных скриптов.

#### Структура директорий:
```text
my_dataset/
├── train/images/
│   ├── pipe1.jpg
│   └── pipe2.jpg
├── val/images/
│   └── pipe3.jpg
├── train_annotations.json
└── val_annotations.json
```

#### Синтаксис `train_annotations.json`:
```json
[
  {
    "image_file": "pipe1.jpg",
    "pipes": [
      {"x": 210.5, "y": 140.0, "r": 35.0},
      {"x": 285.0, "y": 142.2, "r": 34.5},
      {"x": 358.1, "y": 141.0, "r": 36.0}
    ]
  },
  {
    "image_file": "pipe2.jpg",
    "pipes": [
      {"x": 105.0, "y": 90.0, "r": 18.0}
    ]
  }
]
```
- `x`, `y` — абсолютные координаты центра трубы в пикселях изображения.
- `r` — радиус трубы в пикселях.

### Вариант 3: Формат CSV
Самый простой табличный формат (можно редактировать в Excel).

#### Структура директорий:
```text
my_dataset/
├── train/images/
├── val/images/
├── train.csv
└── val.csv
```

#### Синтаксис `train.csv`:
```csv
image,x,y,r
pipe1.jpg,210.5,140.0,35.0
pipe1.jpg,285.0,142.2,34.5
pipe1.jpg,358.1,141.0,36.0
pipe2.jpg,105.0,90.0,18.0
```

---

### Рекомендации по разметке сложных случаев:
1. **Вложенные трубы**: обязательно размечайте обе трубы — и внешнюю трубу большего диаметра, и вложенную в нее трубу меньшего диаметра. Каждая из них имеет свой центр и свой радиус.
2. **Трубы на краях кадра**: если видна хотя бы половина среза трубы, ее следует включить в разметку, указав реальный центр.
3. **Ракурсная эллиптичность**: если фото снято под небольшим углом и срез выглядит слегка овальным, в качестве диаметра берите среднее между горизонтальным и вертикальным размером.

## 5. Обучение нейросети на своих данных

Обучение выполняется через скрипт [train.py](file:///c:/Users/VIGOK/Downloads/%D1%82%D1%80%D1%83%D0%B1%D1%8B/train.py).

### 5.1. Дообучение (Fine-Tuning / Transfer Learning) — РЕКОМЕНДУЕТСЯ
Если у вас собственный датасет из 20–200 фотографий, **наилучший результат** дает дообучение поверх уже имеющихся обученных весов `weights/pipe_counter_best.pth`. Модель уже знает геометрию круглых труб и быстро адаптируется к вашим условиям освещения и металлу:

```bash
python train.py --data_dir "путь/к/my_dataset" --resume weights/pipe_counter_best.pth --epochs 15 --lr 0.0005
```

### 5.2. Обучение с нуля
Если у вас большой датасет (более 300–500 разнообразных снимков) и вы хотите обучить сеть полностью с нуля:
```bash
python train.py --data_dir "путь/к/my_dataset" --epochs 25 --batch_size 12 --lr 0.001
```

### 5.3. Полный список аргументов `train.py`:
- `--data_dir` — путь к корневой директории вашего датасета (по умолчанию `dataset`).
- `--epochs` — количество эпох обучения (по умолчанию `15`). Для дообучения достаточно `10–15`, для обучения с нуля — `20–30`.
- `--batch_size` — количество изображений в одном пакете (по умолчанию `12`). При нехватке памяти уменьшите до `8` или `4`.
- `--lr` — скорость обучения (learning rate). Рекомендуется `0.001` для обучения с нуля и `0.0003 - 0.0005` для дообучения.
- `--img_size` — внутреннее разрешение обработки (по умолчанию `256`). Допустимы `256`, `384` или `512`. Чем выше разрешение, тем выше детализация для очень мелких труб, но требуется больше памяти.
- `--resume` — путь к файлу весов для продолжения обучения.
- `--weights_dir` — каталог для сохранения наилучших весов (по умолчанию `weights`).

### 5.4. Интерпретация логов обучения:
В процессе обучения для каждой эпохи выводится строка вида:
```text
[05/15] (34.2s) loss: 0.0192 | val_loss: 0.0227 | MAE: 0.53 *
```
- `loss` — общая ошибка нейросети на обучающих данных (стремится к 0).
- `val_loss` — ошибка на проверочных данных, не участвовавших в обучении.
- `MAE` (Mean Absolute Error) — **ключевая бизнес-метрика**: средняя абсолютная погрешность подсчета количества труб. Например, `MAE: 0.53` означает, что нейросеть ошибается в среднем менее чем на 1 трубу на кадр!
- Звездочка `*` означает, что на этой эпохе достигнута минимальная ошибка и наилучшая модель автоматически сохранена в `weights/pipe_counter_best.pth`.

## 6. Архитектура нейросети PipeNet

В отличие от стандартных рамочных детекторов (типа Faster R-CNN или YOLO), создающих прямоугольные боксы (Bounding Boxes) с перекрывающимися краями, в проекте реализована специализированная геометро-ориентированная архитектура **PipeNet** (модуль [model.py](file:///c:/Users/VIGOK/Downloads/%D1%82%D1%80%D1%83%D0%B1%D1%8B/model.py)):

1. **Backbone & Feature Decoder**:
   Полносверточная U-Net сеть на легковесных блоках глубинных разделяемых сверток (Depthwise-Separable Convolutions). Архитектура сочетает высокую скорость работы и многоуровневое слияние пространственных признаков.
2. **Heatmap Head (Карта центров)**:
   Выходной слой сигмоида, генерирующий непрерывное поле вероятности нахождения центра трубы. Центры труб моделируются в виде двумерных гауссовых пиков.
3. **Radius Regression Head (Карта радиусов)**:
   Параллельная сверточная голова, регрессирующая точный физический радиус трубы в каждом потенциальном центре.
4. **Sub-pixel Peak Extraction & NMS**:
   Для отделения близко стоящих труб применяется алгоритм локального максимума (2D Max-Pooling NMS 3x3). Поскольку центры смежных труб никогда не совпадают, это исключает склеивание соседних объектов в плотных пачках.

## 7. Решение возможных проблем (Troubleshooting)

### Проблема: При вызове `python count_pipes.py` выводится только слово `Python`
- **Причина**: В Windows активна системная заглушка Windows Store для команды `python`.
- **Решение**: Запускайте через официальный лаунчер Python:
  ```powershell
  py -3.11 count_pipes.py photo.jpg
  ```
  Либо укажите полный путь к интерпретатору:
  ```powershell
  & "C:\Users\VIGOK\AppData\Local\Programs\Python\Python311\python.exe" count_pipes.py photo.jpg
  ```

### Проблема: Ошибка `FileNotFoundError` или ошибка в пути к файлу
- **Причина**: В пути к файлу или папке есть пробелы (например, `images (1).jpg`).
- **Решение**: Всегда оборачивайте пути в кавычки:
  ```powershell
  py -3.11 count_pipes.py "C:\Users\VIGOK\Downloads\images (1).jpg"
  ```

### Проблема: `CUDA out of memory` при обучении
- **Причина**: Недостаточно видеопамяти на GPU для выбранного размера батча.
- **Решение**: Уменьшите размер батча и разрешение:
  ```bash
  python train.py --data_dir my_dataset --batch_size 4 --img_size 256
  ```
